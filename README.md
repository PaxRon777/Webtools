# Weby Toolbox

A sleek, high-performance web development utility suite designed for rapid web prototyping and asset generation. Featuring a modern dark aesthetic with interactive background effects, **Weby Toolbox** provides web developers with essential tools in one unified interface.

## ✨ Features

### 🖼️ Placeholder Generator
Create custom placeholder images on the fly to quickly wire up your UI layouts.
- **Customizable Dimensions:** Set exact width and height in pixels.
- **Color Control:** Choose specific background and foreground colors using hex codes or a visual picker.
- **Format Support:** Generate outputs in JPG, PNG, or GIF formats.
- **Dynamic Text:** Overlay custom text onto your placeholders.

### 🎨 Color & Palette Tools
*Coming soon / Included in the suite.*
- Rapidly generate color schemes and palettes for consistent branding.
- Visual swatches with easy copy-to-clipboard functionality.

### 🚀 Icon Generator
Streamline your iconography workflow.
- **Searchable Library:** Find icons by keyword (e.g., "home", "user", "settings").
- **Dynamic Styling:** Adjust icon size and color instantly.
- **Instant Export:** Generate and download assets ready for production.

## 🛠️ Tech Stack
- **HTML5** - Semantic structure.
- **CSS3** - Custom properties (variables), Flexbox, Grid, and Backdrop Filters.
- **JavaScript** - Dynamic DOM manipulation and Canvas API for image generation.
- https://api.huemint.com/color (API)
- https://img.icons8.com/${sanitizedStyle}/${size}/${color}/${query}.png (API)
- https://dummyimage.com/${width}x${height}/${bgColor}/${fgColor}.${extension}&text=${text} (API)
   

## 🚀 Getting Started

Simply open the `webtools.html` file in any modern web browser to start using the toolbox immediately. No installation required!
